# Sea column — layer model

A lightweight 3D sea-column visualisation in a single `index.html`: animated Gerstner waves, a fading sea volume,
a low-poly seabed with contour lines that drifts through the cut-out, pulsing markers, and a small submarine.
Plain Canvas 2D, no dependencies.

Open `index.html` directly, or view it on GitHub Pages.

Controls: drag to rotate · scroll to zoom · Space + move to pan · 0 to recenter · D drift · R auto-rotate.
All sizes and colours are in the `CFG` block at the top of the script.
